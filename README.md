# 岡山大学医学部 時間割カレンダー

岡山大学医学部のPDFで配布される時間割を、GoogleカレンダーやAppleカレンダー等のカレンダーアプリに読み込める形式（`.ics` ファイル）に変換するプロジェクトです。

手動でのハードコードにより日時・科目をデータ化しています。

## 🔗 カレンダーの購読（自動更新・推奨）

以下のURLをカレンダーアプリに「照会（購読）」として追加することで、時間割が変更・修正された際に自動的にご自身のカレンダーも更新されます。

**購読用URL:**
```text
https://github.com/exact2113/OkaMed-Calendar/releases/latest/download/gakushi_timetable_2026.ics
```

## 📅 カレンダーアプリへの追加（購読）方法

### Googleカレンダー（パソコンからの操作を推奨）
※ スマートフォンのアプリからは追加できないため、一度パソコンのブラウザから追加してください。追加後はスマホアプリにも自動で同期されます。

1. パソコンのブラウザで [Google カレンダー](https://calendar.google.com/) を開きます。
2. 左側のメニューの「他のカレンダー」の横にある **[＋]** ＞ **[URL で追加]** をクリックします。
3. 上記の「購読用URL」を貼り付けます。
4. **[カレンダーを追加]** をクリックします。
*(※ Googleカレンダーの仕様上、更新が反映されるまで最大12〜24時間程度かかる場合があります)*

### Appleデバイス（iPhone / iPad）
1. iPhoneの **「設定」** アプリを開きます。
2. **「カレンダー」** ＞ **「アカウント」** ＞ **「アカウントを追加」** をタップします。
3. **「その他」** ＞ **「照会するカレンダーを追加」** をタップします。
4. 「サーバ」欄に上記の「購読用URL」を貼り付けて **「次へ」** をタップします。
5. 任意の名前（例：医学部時間割）を付け、**「保存」** をタップします。

### Appleデバイス（Mac）
1. Macの標準 **「カレンダー」** アプリを開きます。
2. メニューバーの **「ファイル」** ＞ **「新規カレンダー照会...」** をクリックします。
3. 上記の「購読用URL」を貼り付けて **「照会」** をクリックします。
4. 「自動更新」の頻度を「毎日」や「1時間ごと」等に設定し、**「OK」** をクリックします。

### Nextcloud 等の自鯖カレンダー
1. カレンダーアプリを開き、左メニューの **[＋]**（新しいカレンダーの追加）をクリックします。
2. **[リンクからの新しいサブスクリプション (読み取り専用)]** を選択します。
3. 上記の「購読用URL」を貼り付けます。

## 📥 ファイルを直接ダウンロードしてインポートする場合（手動）

自動更新が不要で、現在の状態を一度だけインポートしたい場合は、ファイルを直接ダウンロードして追加することも可能です。

1. GitHubの **[Releases]** ページを開きます。
2. 最新のリリース（Latest）の **Assets** から `gakushi_timetable_2026.ics` をダウンロードします。
3. 各カレンダーアプリの「インポート」機能から、ダウンロードしたファイルを読み込んでください。

## 📁 リポジトリのファイル構成

このプロジェクトは以下のような構造になっています。

- `scripts/` : 時間割データを生成するためのPythonスクリプトが入っています。（例: `generate_2026.py`）
- `data/` : データ入力の参考用として、大学から配布された元データのPDFを保管しています。
- `.github/workflows/` : GitHub Actionsを利用して、タグ付け時にICSファイルを自動生成・リリースするための設定ファイルです。

## 🤝 開発への参加・修正協力のお願い

クラスメイトの皆さんからの修正や、次年度以降のデータ追加（Pull Request）を歓迎します！
PDFの変更や休講・補講による変更があった場合は、以下の手順でご協力をお願いします。

1. GitHubアカウントを作成し、このリポジトリを **Fork（フォーク）** します。
2. 自分のリポジトリ内で `scripts/` 内の該当するPythonスクリプト（例: `generate_2026.py`）を編集し、日付や時限、科目名を修正・追加します。
3. 修正が終わったら **Commit** し、元のリポジトリに対して **Pull Request（プルリクエスト）** を送信してください。
4. 管理者が内容を確認しMerge（結合）した後、新しいバージョンのICSファイルが自動的にReleasesに公開されます（購読しているカレンダーにも自動で反映されます）。

**技術的な質問がある場合:** 
Issueタブから新しくIssueを立てて質問や要望を書いてください。
