# 岡山大学医学部 時間割カレンダー

岡山大学医学部のPDFで配布される時間割を、GoogleカレンダーやAppleカレンダー等のカレンダーアプリに読み込める形式（`.ics` ファイル）に変換するプロジェクトです。

手動でのハードコードにより日時・科目をデータ化しています。

## 📥 最新のカレンダー（ICSファイル）のダウンロード

最新の `.ics` ファイルは、GitHubの **Releases** ページからダウンロードできます。

1. パソコンまたはスマートフォンのブラウザで、画面右側にある **[Releases]** をクリックします。
2. 最新のリリース（Latest）の **Assets** の中にある `gakushi_timetable_2026.ics` などのファイルをクリックしてダウンロードしてください。

---

## 📅 カレンダーアプリへのインポート方法

### Googleカレンダー（パソコンからの操作を推奨）
※ スマートフォンのGoogleカレンダーアプリからは直接インポートできないため、ブラウザを使用してください。一度ブラウザでインポートすれば、スマホアプリにも自動で同期されます。

1. パソコンのブラウザで [Google カレンダー](https://calendar.google.com/) を開きます。
2. 右上の **歯車マーク（設定）** ＞ **[設定]** をクリックします。
3. 左側のメニューから **[インポート / エクスポート]** をクリックします。
4. 「パソコンからファイルを選択」をクリックし、ダウンロードした `.ics` ファイルを選択します。
5. 追加先のカレンダーを選択します。（※既存の予定と混ざらないよう、左メニューの「カレンダーを追加」から事前に時間割専用の新しいカレンダーを作成しておくことを強くおすすめします。）
6. **[インポート]** をクリックします。

### Appleデバイス（iPhone / iPad / Mac）
最も簡単な方法です。

1. iPhone等の標準ブラウザ（Safari等）でReleasesページから `.ics` ファイルをダウンロードします。
2. ダウンロードしたファイルをタップ（Macの場合はダブルクリック）します。
3. 標準のカレンダーアプリが起動し、「すべてのイベントを追加」等の確認画面が出ますので、追加を許可してください。

### Nextcloud 等の自鯖カレンダー
1. カレンダーアプリを開き、「カレンダーのインポート」または「設定」を選択します。
2. ダウンロードした `.ics` ファイルをアップロードし、インポート先のカレンダーを指定してください。

## 📁 リポジトリのファイル構成

このプロジェクトは以下のような構造になっています。

- `scripts/` : 時間割データを生成するためのPythonスクリプトが入っています。（例: `generate_2026.py`）
- `data/` : データ入力の参考用として、大学から配布された元データのPDFを保管しています。
- `.github/workflows/` : GitHub Actionsを利用して、タグ付け時にICSファイルを自動生成・リリースするための設定ファイルです。

## 🤝 開発への参加・修正協力のお願い

クラスメイトの皆さんからの修正や、次年度以降のデータ追加（Pull Request）を歓迎します！
PDFの変更や休講・補講による変更があった場合は、以下の手順でご協力をお願いします。

1. GitHubアカウントを作成し、このリポジトリを **Fork（フォーク）** します。
2. 自分のリポジトリ内で `scripts/` 内の該当するPythonスクリプト（例: `generate_2026.py`）を編集し、日付や時限、科目名を修正・追加します。
3. 修正が終わったら **Commit** し、元のリポジトリに対して **Pull Request（プルリクエスト）** を送信してください。
4. 管理者が内容を確認しMerge（結合）した後、新しいバージョンのICSファイルが自動的にReleasesに公開されます。

**技術的な質問がある場合:** 
Issueタブから新しくIssueを立てて質問や要望を書いてください。
